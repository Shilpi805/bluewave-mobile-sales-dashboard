# Bluewave Mobile Sales Dashboard
## Project Objective
The objective of this project is to develop an interactive Power BI dashboard that transforms raw mobile sales data into meaningful business insights. The dashboard enables stakeholders to monitor sales performance, evaluate customer behavior, analyze regional trends, and make data-driven decisions through dynamic visualizations and KPIs.
